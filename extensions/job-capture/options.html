Letter Writer Capture

Queue jobs (direct to Firestore)

With queueing on (the checkbox below), sending a page writes the job straight to Firestore — like the phone app — and the desktop batch drafts it on its next run. No local server needed. This needs a one-time Google sign-in with the same account the phone app uses. On browsers without extension sign-in (Firefox for Android) the page is handed to the Letter Writer app instead, which queues the job itself.

  2. Then click Sign in with Google above and pick the same account as the phone app.

No Firebase console step: the extension signs in through the Firebase Auth REST API, and the authorized-domains list is only enforced for the Firebase JS SDK and the hosted auth handler — not for REST calls. (That field also rejects chrome-extension://… and moz-extension://… entries: it wants a domain name.)

The redirect URI never changes — register it once. On Firefox the label is the SHA-1 of the add-on ID in the manifest (browser_specific_settings.gecko.id), so it is the same whether the add-on is loaded unpackaged or installed signed, in any profile, and across updates and reinstalls. On Chrome/Edge it is keyed to the extension ID, which the signing key in keys/ pins for packaged installs (an unpacked load gets a path-derived ID, hence a different URI — register the one shown here for the copy you installed). If sign-in fails with redirect_uri_mismatch, the URI is not registered (exactly, no trailing slash) or sits on the wrong client.

Stash flow (app origin)

With queueing off, captured pages are sent to this origin, then Letter Writer opens with ?capture= so extraction can run in your logged-in session.

Production Docker: https://localhost:8443. UI harness (ui-harness/scripts/up.sh): http://127.0.0.1:3010.

On: sending a page creates or updates the job in the pipeline and the desktop drafts it on its next run — no intake tab, no local server needed. Off: the page is sent to the app origin above and Letter Writer opens with it so you can review the extraction first.
